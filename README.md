# Customer Support Analytics

A collaborative portfolio project focused on analyzing customer support data to identify trends, monitor support performance, and generate actionable business insights.

## Project Objective

The objective of this project is to analyze customer support ticket data and provide insights into support performance, including ticket volume, status, response time, resolution time, and unresolved tickets.
## Dataset

The project uses the **Customer Support Ticket Dataset** from Kaggle.

- **Records:** 8,469
- **Columns:** 17
- **License:** CC0: Public Domain

### Key fields

- Ticket ID
- Product Purchased
- Ticket Type
- Ticket Subject
- Ticket Status
- Ticket Priority
- Ticket Channel
- First Response Time
- Time to Resolution
- Customer Satisfaction Rating
- Date of Purchase
- Ticket Description

The dataset provides the information required to analyze ticket volume, ticket status, priority, support channels, response time, resolution time, and customer satisfaction.
