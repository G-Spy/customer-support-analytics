# Customer Support Analytics

A collaborative portfolio project focused on analyzing customer support data to identify trends, monitor support performance, and generate actionable business insights.

## Project Objective

The objective of this project is to analyze customer support ticket data and provide insights into support performance, including ticket volume, status, response time, resolution time, and unresolved tickets.

## Project Approach

The project combines:

- Business Analysis
- Agile project management
- Data analysis
- REST API development
- Data visualization
